# Windows offline release

Target: Windows 10/11, AMD64, Python 3.11.9, CPU PyTorch.
Runtime execution does not install packages or access the internet.

The application keeps the original `.pt` checkpoint and original YOLOv5 preprocessing,
NMS and box coordinate scaling. `vendor/yolov5/STATION_PATCHES.md` records the small
offline import changes to the matching source commit.

Build inputs:

- `.build/downloads/python-3.11.9-embed-amd64.zip` from
  <https://www.python.org/ftp/python/3.11.9/python-3.11.9-embed-amd64.zip>.
- `.build/wheels-windows/`, generated by `download_windows_wheels.py`. The downloader
  evaluates dependency markers as Windows, even when the builder runs on Linux.
- `.build/vc-runtime/`: unmodified x64 Microsoft Visual C++ Runtime DLLs, license files,
  and `manifest.json` extracted from the official redistributable. The current source
  URL, version and SHA-256 are recorded in the release's `runtime/VC_RUNTIME_MANIFEST.json`.
- Project `weight/last.pt`, `config.json`, and the pinned `vendor/yolov5` source.
- Host `ffmpeg` to create the short demo video.

Commands from the station project directory:

```bash
python3 deploy/download_windows_wheels.py --wheelhouse .build/wheels-windows
python3 deploy/download_windows_wheels.py --wheelhouse .build/wheels-windows --check-only
python3 deploy/build_windows.py --no-zip
# Validate dist/station_tcp_windows with its own Windows runtime, then:
python3 deploy/build_windows.py --archive-only
```

`requirements-windows.lock` records the complete tested dependency versions;
`manifest.json` records the actual wheel filenames and SHA-256. Preserve the wheelhouse
and the lock together for reproducible releases. On Windows use the package's
`SELF_CHECK.cmd`; the build directory also contains Wine-based compatibility validation
tools. Wine checks do not validate a physical camera, desktop display, or an external
upper-computer server on the target Windows machine.

Release layout and user instructions are in `README_WINDOWS.txt`. The ZIP contains
private Python, libraries, model, editable configuration, application/vendor source,
sample inputs, startup commands, third-party licenses and checksums.
