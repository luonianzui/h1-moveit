## 两个面板按钮

按用户最新要求，两个圆形按钮从上沿移到朝向机器人的正面上部，取代原正面红按钮：

- **蓝色 / 方形标记：开关盖**。闭合时点击打开到 120°；打开后再次点击关闭到 0°。
- **绿色 / 圆形标记：启动/停止**。关闭盖子并停稳后点击，转子加速至演示值 30 rpm；
  再点一次减速停止。完全停稳前不能开盖。

鼠标左键释放时触发，按住不连发，0.5 秒防抖；移动视角、右键、修饰键、
面板空白区域不会触发。GUI 按可见按钮 visual 拾取，不使用固定屏幕热区。

(-0.275448466003,-0.13,0.261427679186) m，中心间距260 mm，世界高度约1.0764 m。
机器人视角左蓝右绿，两侧对称，避开中间装饰区域。沿原STL前面板法向安装，
外向法向约(-0.97898044,0,0.20395417)，帽轴RPY=(0,-1.365401024067,0) rad；
按压接近方向为相反法向，约朝+X并略向下。底座嵌入面板1 mm、外露3 mm，
帽面外露12 mm；不修改原CAD网格。r119已验证机器人IK/FCL与接触触发，
默认仍为鼠标交互；enable_robot_press:=true显式启用接触传感节点，但不自动发布轨迹。
按钮帽直径 26 mm、黑底座直径 34 mm，属于新增仿真交互几何，不是交付 CAD 零件。

## 盖子几何与命令行

闭合 0°，最大 120°仍是依据用户第二张图片的近似值，不是 CAD 精确机械止挡。
lid_hinge_joint 转轴沿模型 +Y，原合页圆柱确定的中心
(0.2680710507631302,0,0.307) m；盖子和左右上半合页一起转动。
原交付角约 31.763140434°，闭合模型下表面距箱体顶面约 2 mm；原 STL 不改。
JointPositionController effort PID=100/50/10，限位 0..120°、限速 0.35 rad/s、限矩30 Nm。
盖子2 kg、固定箱体20 kg及其惯量仍是仿真假设，不是交付CAD测量。

保留原命令行，但现在同样必须通过转子互锁：

```bash
bash run_centrifuge_lid.sh status
bash run_centrifuge_lid.sh open
bash run_centrifuge_lid.sh close
bash run_centrifuge_lid.sh 60
```

默认/status只读。只运行一个盖子命令；拒绝非有限/超限目标与其他发布者；
完成门仍为角误差<0.2°、速度<0.01 rad/s、稳定0.5秒。
90秒超时、反馈丢失等错误请求保持，按钮节点锁存helper故障。
盖子运行中点击不排队、不反向。中间位置以实测半程判断下一端点。

## 转子与互锁

支架绕模型 +Z 转动；两只吊篮已从刚性 rotor link 拆分为独立刚体，
通过 bucket_left_swing_joint / bucket_right_swing_joint 被动铰接到支架。
没有吊篮角度指令、位置控制器、伪造离心力或按转速播放的倾角动画；
由 Gazebo 重力、多刚体惯性和关节阻尼产生外摆、摆动与回落。
仍不模拟样品流体、分离效果、承载强度或高转速结构安全。

转子轴心仍为模型 (0.0305710511262894,0,0.225) m。原STL不改；
从原安装圆柱拟合吊篮轴，半径7.5 mm，拟合残差小于0.00006 mm，
轴距转子90 mm、模型高237.5 mm。两个铰轴均沿各自切向；
局部轴 (0,-1,0)，正角为向外摆。初始网格绕原轴调整为质心在轴正下方，
不是改变零件尺寸；可逆恢复原交付姿态误差小于1.4e-17 m。

按均匀密度2700 kg/m³积分原网格体积、质心和完整惯量张量：
支架1.179530 kg，两吊篮各约0.517251 kg，吊篮质心低于轴约13.071 mm。
密度/质量是仿真假设，非实物称量；空吊篮、不含样品。
阻尼0.003 N·m·s/rad、无弹簧/静摩擦，限位-20°..85°也是模型假设。
开启吊篮自碰撞；同一父子铰链的接触仍受物理引擎邻接过滤。
当前30 rpm的独立能量平衡预测外摆约4.926°，不是强制目标。
计算证据见r113 geometry_contract.json；关节语义依据
[SDFormat规范](https://sdformat.org/spec/1.9/joint/)。

演示目标30 rpm（π rad/s），速度指令斜坡1 rad/s²，力矩输出限制±2 Nm，
关节速度上限4 rad/s。真实设备额定转速未知，本结果不是高转速离心认证。
全假设摆角范围吊篮最大扫掠半径165.431 mm；仅比较外壳顶部219 mm半径
不构成完整碰撞证书，实际动态验证另见r113报告。

CentrifugeInterlock 在 Gazebo server 读取真实盖角、盖速与转速并控制命令准入：

- 开盖前要求转子未启用、实测与指令转速均<0.02 rad/s。
- 默认启动前要求盖角与目标角<0.2°、盖速<0.01 rad/s，且转子已停。
- 显式开盖演示允许非零盖角，但实际/目标误差必须<0.2°且盖速<0.01 rad/s。
- 减速期间保持开盖禁用；已发开盖目标时，即便盖尚未移动也禁止启动。
- 失去ROS按钮节点1秒墙钟心跳、盖角异常或反馈无效时撤销运行并减速。
- ROS按钮与CLI前置检查外，server仍独立拦截受支持公共请求接口的非法请求。

该互锁仅为Gazebo演示的软件保护，不是硬件安全回路；
直接注入内部applied_angle、修改物理状态或其他私有旁路不属于支持接口。
不得用于实体离心机或机器人。

## ROS / Gazebo 接口

| Topic | 类型 | 语义 |
| --- | --- | --- |
| /centrifuge/button/action | String | GUI发lid或rotor点击事件 |
| /centrifuge/lid/target_angle | Float64 | 外部盖角请求，rad，经过互锁 |
| /centrifuge/rotor/enable | Bool | true启动请求、false停止请求 |
| /centrifuge/machine/heartbeat | Bool | 按钮节点10Hz租约，禁止伪造以绕过失联停机 |
| /centrifuge/machine/status | String JSON | ready、转速、盖角、can_open/can_start、拒绝计数 |
| /centrifuge/button/status | String JSON | 按钮/helper忙、错误与完成状态 |
| /centrifuge/joint_states | JointState | 盖子、转子及两个被动吊篮关节 |

Gazebo内部 /centrifuge/lid/applied_angle 由互锁发布给原PID，不是用户控制入口。
旧 /centrifuge/button/press 已停用。状态话题中浮点数是显示精度；
精密角度审计使用JointState。
