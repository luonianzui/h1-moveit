## 修正
`centered_exit.py`仅在原取回轴向阶段碰撞拒绝后，尝试最多2毫米的篮局部X方向居中，姿态和局部Y不变，再沿篮轴离开。新路径不豁免盒子—篮体接触，全部经过原2mrad密碰撞、关节界和姿态检查；其他失败不吞掉。原始抓持参考和请求不改。

实际r358快照只需0.906372毫米居中，完整取回几何2269次检查通过。r356左/右成功快照分别2215/2617次检查通过，不触发居中分支。9项单元测试通过；报告见`centered_exit_qualification.json`。这是几何资格，不是新物理成功。

集成于全新r359，原正式模型/源文件、r356及此前成功不变。主流程的阶段首尾以修正后实际目标衔接，不把名义轴向目标偷偷恢复。
