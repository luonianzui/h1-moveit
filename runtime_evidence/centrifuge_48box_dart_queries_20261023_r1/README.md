# DART单次求解查询缓存实验（2026-10-23）

仅用于新身份r354的固定骨盆Gazebo离心机操作。r353及此前所有正式文件、模型、轨迹、时钟和物理门保持；不替换系统DART。

## 假设和改动
在r353同序约束组装器内，以RAII作用域缓存BodyNode所属Skeleton及isReactive的纯查询结果。作用域仅覆盖一个非拓扑变更的求解调用，退出即清空，线程独立；任何作用域外调用原安装函数。真实速度增量与isImpulseApplied仍逐次读取，不缓存响应数值、不跨物理步复用，不改矩阵算术、回调次序、摩擦、质量、步长、求解器及fallback策略。

库仍命名libDartConstraintCache.so以兼容既有进程注入接口，但新库哈希独立，来源为本目录。只给新Gazebo进程树设置LD_PRELOAD，没有修改全局环境或系统共享库。旧r348重排谓词版本未加载。

## 验证
- 隔离colcon构建，six miniconda library before/after字节一致。
- 105矩阵输入/脉冲输出/回调顺序测试，含空组、fallback、NaN策略；1200接触世界步逐字节一致。
- 新增5400世界步、43200状态向量检查：三个场景覆盖堆叠、关节链与限位、多根同Skeleton和自碰撞，步间切换mobile和LOCKED/PASSIVE。
- 5088接触步；41113456命中/29228首次查询，18855141实际接触响应，退出缓存引用数零。
- 两轮新组件相对关闭查询缓存（其余同r353组装器）速度比1.149354/1.148597；仅组件测量，不是全任务或稳定1倍实时证明。
- 新任务须另行完整运行、物理核验、原速录像与性能测量；不能用组件结果代替成功。

## 来源与保留
官方DART v6.13.2的BodyNode.cpp、ContactConstraint.cpp、BoxedLcpConstraintSolver.cpp随本目录保留原许可证；安装库与头文件在r354依赖清单绑定。源码为过程内候选，不改原安装。build中的安装符号链接目标为后续运行依赖，不可当作无用缓存清理。
